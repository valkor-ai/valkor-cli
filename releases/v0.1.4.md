## Compared with v0.1.3

### Added

- Desktop installers for macOS (Apple Silicon and Intel), Windows 64-bit, and Linux x86_64.

### Improved

- Session digests can read a stopped session's saved transcript.
- Session deletion retries stalled or failed requests instead of leaving the command waiting indefinitely.
- Desktop startup, session error display, and Valkor app icons.

### Release artifacts

- Four CLI binaries for macOS and Linux, with SHA256 checksums.
- Desktop DMG, Windows installer, and Linux AppImage.
- Desktop update metadata and the macOS update ZIP.

Desktop installers in this release are unsigned. macOS and Windows may show a security warning, and in-app automatic updates require signed builds.
