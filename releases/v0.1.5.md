## Compared with v0.1.4

### Added

- Connect your computer from the desktop app with access approval and menu-bar controls.
- Run Computer Use on macOS with guided Accessibility and Screen Recording permissions.
- Expose Valkor CLI commands through a local MCP server.
- List and download saved session attachments, including attachments from stopped sessions.

### Improved

- Reopen the last project when the desktop app starts.
- Copy the current session URL from the desktop Go menu.
- Update session labels and metadata from the CLI.
- Save connector results with the `--out` option.
- Show clearer login, host selection, JSON output, and installation errors.

### Release artifacts

- CLI binaries for macOS and Linux on arm64 and x64.
- Desktop installers for macOS, Windows, and Linux.
- A universal macOS DMG and update ZIP, plus desktop update metadata.
- SHA256 checksums for the CLI binaries.

Desktop installers in this release are unsigned. macOS may show a security warning, and in-app automatic updates require signed builds.
